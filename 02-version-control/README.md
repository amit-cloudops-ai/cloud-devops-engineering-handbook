# 02 — Version Control & Collaboration

Use Git as an engineering workflow: safe changes, reviewable history and recoverability.

## Topics
- Working tree, index, commit objects, branches, tags, refs and remotes.
- Merge, rebase, cherry-pick, revert, reset, reflog and bisect.
- Conflict resolution, interactive rebase and recovery.
- Pull requests, code review, branch protection and CODEOWNERS.
- Release tags, changelogs, GitHub Actions and artifact provenance.

## Tools
Git CLI, GitHub and gh CLI.

## Interview path
Questions 41–45 in the [question bank](../INTERVIEW-QUESTION-BANK.md); Git scenarios in the [scenario playbook](../SCENARIO-PLAYBOOK.md).

**Exit gate:** resolve a realistic conflict, recover a mistaken change safely and explain the difference between revert and reset.
