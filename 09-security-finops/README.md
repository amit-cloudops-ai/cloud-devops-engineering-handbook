# 09 — Security, DevSecOps & FinOps

Build secure defaults and cost awareness into design, delivery and operations.

## Security topics
- Threat modeling, trust boundaries and attack surface.
- IAM least privilege, workload identity, RBAC and network segmentation.
- Secret management, rotation and secret scanning.
- SAST, DAST, SCA, container and IaC scanning.
- SBOM, image signing, provenance and dependency pinning.
- Kubernetes security contexts, admission controls and audit logging.
- Encryption, key management, vulnerability response and incident evidence.

## FinOps topics
- Cost allocation, tags, budgets, forecasts and anomaly detection.
- Compute, storage, network egress, logs and idle-resource cost drivers.
- Rightsizing, autoscaling, spot trade-offs and commitments.
- Cost per request, per tenant, per workload and per token.

## Tools
Trivy, Semgrep, Gitleaks, Checkov, OPA/Conftest, Kyverno, Falco, Cosign, Syft, Vault, AWS Budgets and Cost Explorer.

## Interview path
Questions 166–175; cloud/security scenarios in the [scenario playbook](../SCENARIO-PLAYBOOK.md).

**Exit gate:** review an infrastructure change for identity, network, secrets, supply-chain and cost risks.
