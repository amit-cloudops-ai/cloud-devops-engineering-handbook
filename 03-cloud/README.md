# 03 — Cloud Engineering (AWS-first)

Develop the ability to design, operate and troubleshoot secure cloud infrastructure. AWS is the primary implementation platform; Azure and GCP are comparative follow-on tracks.

## AWS topics
- Identity: IAM roles, trust policies, STS, federation, OIDC, SCPs and permission boundaries.
- Networking: VPC, subnets, route tables, IGW, NAT, endpoints, PrivateLink, peering, Transit Gateway, VPN and Direct Connect.
- Compute: EC2, Auto Scaling, Lambda, ECS and EKS.
- Storage/data: S3, EBS, EFS, RDS, DynamoDB and backup.
- Edge/integration: Route 53, CloudFront, ALB/NLB, API Gateway, SQS, SNS and EventBridge.
- Operations: CloudWatch, CloudTrail, Config, Systems Manager, KMS, Secrets Manager, Budgets and Cost Explorer.

## Tools
AWS Console, AWS CLI, IAM Access Analyzer, CloudWatch, CloudTrail, Systems Manager and the AWS emulator for local exercises.
