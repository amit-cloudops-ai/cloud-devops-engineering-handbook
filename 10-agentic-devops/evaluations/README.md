# Agent Evaluation

Evaluate agents against a fixed, versioned dataset rather than isolated demonstrations.

Measure task correctness, evidence quality, tool selection, completion rate, latency, cost, refusal behaviour and unsafe-action prevention. Include ambiguous requests, missing permissions, stale information, malformed tool outputs, timeouts, prompt injection and partial failures.

Record model / prompt / tool versions and regression results. A successful response is not sufficient if the agent took an unsafe action or fabricated evidence.
