# AWS Infrastructure Auditor

**Documentation status:** Initial project record. Inspect the implementation and tests before describing features as complete.

## Intended outcome
Produce structured, evidence-backed assessments of selected AWS configuration. Begin with read-only inventory and analysis.

## Required evidence
- [ ] AWS services and resources in scope.
- [ ] Authentication and least-privilege policy.
- [ ] Finding data model and severity definitions.
- [ ] Pagination and error handling.
- [ ] Test fixtures and evaluation cases.
- [ ] Sanitized example report.
- [ ] Cost, limits and known gaps.

The auditor must not change AWS resources by default. Recommendations are not automatically executed.
