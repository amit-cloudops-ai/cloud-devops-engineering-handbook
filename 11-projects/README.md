## Evidence checklist
- [ ] Problem, users, scope and non-goals.
- [ ] Architecture and data flow.
- [ ] Threat model and permissions.
- [ ] Reproducible setup and prerequisites.
- [ ] Tests and evaluation results.
- [ ] Sanitized demo output.
- [ ] Cost and cleanup notes.
- [ ] Known limitations and next steps.

Do not claim production readiness unless deployment, security, reliability and operational controls have been verified.
