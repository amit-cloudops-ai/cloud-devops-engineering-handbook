# 08 — Observability & Site Reliability Engineering

Use telemetry and operational practices to detect, understand and reduce service failures.

## Topics
- Metrics, logs, traces, events, correlation IDs and context propagation.
- RED/USE methods, cardinality, sampling and alert design.
- Prometheus, PromQL, Grafana, Alertmanager and OpenTelemetry.
- SLIs, SLOs, SLAs, error budgets and burn-rate alerts.
- Incident severity, communication, command, mitigation and postmortems.
- Capacity planning, load testing, resilience, backups and disaster recovery.
- RTO, RPO, HA and chaos engineering.

## Tools
Prometheus, Grafana, Loki, Tempo, Jaeger, OpenTelemetry, OpenSearch/ELK, k6 and Locust.

## Interview and lab path
Questions 139–152; scenarios 61–70; LAB-SRE-01.

**Exit gate:** investigate an incident using metrics/logs/traces, write an actionable postmortem and explain an SLO-based decision.
