**Review policy:** Recheck repository activity, instructions, licences, versions and cost requirements before starting a resource. A README description is not proof that every linked exercise is current or safe.

## How to select a resource

1. Start from a skill gap in a target job description or the handbook roadmap.
2. Prefer official documentation for expected product behaviour.
3. Choose one primary explanation and one practical exercise; avoid parallel resource collecting.
4. Record prerequisites, access model, estimated time, version, cost and cleanup.
5. Produce original evidence in this handbook: notes, commands, test results, failure diagnosis and interview answers.
6. Revisit links periodically. Do not assume a repository remains maintained or its README statistics remain current.

## External content and attribution

Do not copy large sections, answer banks, diagrams or project code into this repository. Link to the source, summarize in your own words, respect each repository's licence and attribution terms, and keep private or recalled interview material out of the handbook.
