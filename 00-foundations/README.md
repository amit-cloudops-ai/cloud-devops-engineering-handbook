# 00 — Foundations

The operating-system and network knowledge expected across Cloud, DevOps, SRE and Platform roles.

## Software delivery lifecycle
- [SDLC study notes](SDLC.md) — stages, models, DevOps/CI/CD, DevSecOps and interview revision.

## Topics
- Linux architecture, boot, filesystem, permissions, users and groups.
- Processes, threads, signals, systemd, services, logs and scheduling.
- CPU, memory, swap, storage, inodes, I/O and kernel troubleshooting.
- DNS, IP addressing, CIDR, routing, ARP, ICMP, TCP, UDP and ports.
- HTTP/HTTPS, TLS, certificates, proxies, NAT, firewalls and load balancing.
- SSH, remote access, packet capture and troubleshooting methodology.

## Practical tools
Linux CLI, Bash, systemd, journalctl, ps, top, free, df, du, lsof, ss, ip, dig, curl, openssl, tcpdump, Wireshark and traceroute.
