# 01 — Programming & Automation

Build reliable automation for infrastructure operations; scripts should be safe, testable and observable.

## Topics
- Bash: quoting, pipes, exit codes, traps, strict mode, idempotence and cleanup.
- Python: data structures, modules, exceptions, typing, virtual environments and packaging.
- API automation: HTTP, authentication, pagination, retries, timeouts and rate limits.
- JSON/YAML/CSV processing, subprocess safety and environment variables.
- Unit tests, mocks, logging, linting and dependency management.
- Concurrency, async I/O and defensive input validation.

## Tools
Bash, Python 3, pytest, requests/httpx, jq, yq, Make and pre-commit.

## Interview and lab path
See [skill matrix](../SKILL-MATRIX.md), questions 41–55 and scenarios 1–10 in the [practice banks](../INTERVIEW-QUESTION-BANK.md).

**Exit gate:** produce one tested operational script and one tested API automation utility with error handling, structured logs and safe defaults.
