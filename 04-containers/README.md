# 04 — Containers

Understand container build, runtime, networking, storage, isolation and operational failure modes.

## Topics
- Image layers, registries, tags, digests and build cache.
- Dockerfiles, multi-stage builds, build context and non-root execution.
- Volumes, bind mounts, bridge networks, DNS and port publishing.
- Compose services, health checks, dependency behavior and environment configuration.
- Resource limits, logs, inspect, exec, events and lifecycle.
- Image scanning, SBOM, signing, secret handling and minimal images.

## Tools
Docker Engine, Docker CLI, Compose, BuildKit, ECR/GHCR, Trivy, Syft and Cosign.

## Interview and lab path
Questions 81–92; scenarios 31–38; LAB-DOCKER-01.

**Exit gate:** build and run a multi-container service, then diagnose network, volume, configuration and image failures.
