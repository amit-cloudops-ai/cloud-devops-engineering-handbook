# 05 — Kubernetes & Orchestration

Learn Kubernetes architecture and operational troubleshooting before adding platform frameworks.

## Topics
- Control plane, API server, etcd, scheduler, controllers and kubelet.
- Pods, Deployments, StatefulSets, DaemonSets, Jobs and CronJobs.
- Services, EndpointSlices, Ingress, Gateway API, DNS and CNI.
- ConfigMaps, Secrets, service accounts, RBAC and admission.
- Requests/limits, QoS, probes, HPA, PDB, affinity, taints and tolerations.
- PV, PVC, StorageClass and CSI.
- Rollouts, rollbacks, upgrades and cluster troubleshooting.

## Tools
kubectl, kind, minikube, k3d, Helm, Kustomize, k9s, stern and Killercoda.

## Interview and lab path
Questions 93–112; scenarios 39–50; LAB-K8S-01.

**Exit gate:** deploy a workload, expose it with a Service and diagnose Pending, CrashLoopBackOff, ImagePullBackOff, DNS and storage issues.
