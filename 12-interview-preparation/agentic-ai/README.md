# Agentic AI Operations Interview Track

Be prepared to explain:
- Deterministic automation vs an agentic workflow.
- Tool calling, schemas, state, retries, idempotency and timeouts.
- How identity and authorization are enforced.
- How prompt injection in logs or retrieved documents is contained.
- How humans approve risky actions.
- How accuracy, tool choice and safety are evaluated.
- What happens when a tool fails, times out or returns partial data.
- How auditability and rollback are implemented.

See [the agentic safety model](../../10-agentic-devops/safety-model.md).
