# Resume tailoring workflow

This folder contains the canonical resume source and JD-tailoring playbook.

- [Resume Playbook](RESUME-PLAYBOOK.md) — verified facts, hard rules, ATS/JD matching workflow, bullet-writing standards and interview-safe claim restrictions.
- [Base LaTeX template](base-resume.tex) — preserved one-page pdfLaTeX template. Tailored versions must retain its layout and macros.

## How to use

Whenever Amit provides a job description:

1. Read the playbook and use only its verified facts plus the supplied JD.
2. Extract the JD's must-have skills and map each to Have / Partial / Missing.
3. Reorder skills and prioritize relevant evidence without adding unverified tools, metrics or claims.
4. Preserve the LaTeX structure, one-page format and layout macros.
5. Return one complete compilable Overleaf script, the Have / Partial / Missing table, and up to three focused questions for missing facts.
6. Never include graduation/pass-out year, CGPA or percentage in the resume.
7. Keep every claim defensible in a technical interview. Ask before claiming in-progress work is deployed.

## Source of truth

The playbook's Verified Facts section is the source of truth for resume content. The base template is the source of truth for formatting. If a JD asks for something not supported by the verified facts, mark it Missing rather than inventing experience.
