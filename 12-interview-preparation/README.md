# Interview Preparation

Prepare by role while building from shared fundamentals.

## Tracks
- DevOps: Linux, Git, scripting, Docker, CI/CD, cloud and troubleshooting.
- Cloud: networking, IAM, compute, storage, security, monitoring and cost.
- Platform: Kubernetes, automation, IaC, developer workflows and reliability.
- SRE: Linux, networking, observability, SLI/SLO, incidents, capacity and resilience.
- Agentic DevOps: agent/tool design, safety, evaluation and operational integration.

## Question depth
1. Foundational — define and explain.
2. Mechanistic — explain how it works.
3. Practical — demonstrate commands or configuration.
4. Troubleshooting — diagnose from evidence.
5. Design — choose an approach and defend trade-offs.

Answer aloud without reading. State assumptions, ask clarifying questions when needed, and be honest about what you have not used or verified in production.
