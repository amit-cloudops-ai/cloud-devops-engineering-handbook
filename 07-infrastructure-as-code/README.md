# 07 — Infrastructure as Code

Treat infrastructure definitions as versioned, reviewed and testable software.

## Topics
- Terraform lifecycle, providers, resources, data sources, variables, outputs and locals.
- State, remote backends, locking, imports, moved blocks and recovery.
- Modules, version constraints, provider lock files and environment separation.
- Dependency graph, drift, lifecycle rules, count and for_each.
- Secrets, state encryption and access boundaries.
- Policy-as-code, validation and CI plan review.
- Ansible configuration management and Packer image building concepts.

## Tools
Terraform, OpenTofu, tflint, Trivy, Checkov, OPA/Conftest, Terratest, Ansible and Packer.

## Interview and lab path
Questions 125–138; scenarios 56–60; LAB-IAC-01.

**Exit gate:** review a plan, explain state and drift, and demonstrate safe changes without applying unapproved cloud resources.
