# 13 — System Design & Distributed Systems

Practise architecture decisions for resilient, secure, observable and cost-aware systems.

## Topics
- Load balancing, caching, CDN, API gateways and service discovery.
- Relational and NoSQL databases, indexes, replication, partitioning and sharding.
- Queues, streams, event-driven systems and asynchronous processing.
- Consistency, CAP trade-offs, ordering, idempotency and deduplication.
- Timeouts, retries, jitter, circuit breakers, bulkheads and backpressure.
- High availability, multi-AZ/region, disaster recovery and failure domains.
- Multi-tenant security, identity, observability and FinOps.

## Design method
1. Clarify functional and non-functional requirements.
2. Estimate traffic, storage, latency and availability targets.
3. Draw the request/data flow and trust boundaries.
4. Identify stateful components and failure domains.
5. Define scaling, resilience, observability and security controls.
6. Explain trade-offs and staged implementation.
