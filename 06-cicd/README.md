# 06 — CI/CD & Release Engineering

Build secure and repeatable delivery pipelines from source change to verified deployment.

## Topics
- Pipeline stages, triggers, runners, artifacts, caches and environments.
- Build, test, scan, sign, publish, deploy, verify and rollback.
- GitHub Actions, Jenkins and GitLab CI concepts.
- Secrets, OIDC, runner isolation, permissions and supply-chain security.
- Immutable artifacts, SBOM, provenance and dependency pinning.
- Rolling, blue-green and canary releases.
- GitOps reconciliation with Argo CD or Flux.

## Tools
GitHub Actions, Jenkins, GitLab CI, Argo CD, Flux, ECR/GHCR, Renovate, Dependabot, Trivy and Cosign.

## Interview and lab path
Questions 113–124; scenarios 51–55; LAB-CICD-01.

**Exit gate:** create a pipeline with tests, artifact handling, security checks, controlled deployment and a rollback/verification strategy.
